## 使用原则

1. **一张图最多用一个方案** — 不要混搭
2. **主色不超过 3 种** — 主要 + 次要 + 强调
3. **连线颜色统一** — 除非有语义区分（成功/失败）
4. **分区背景要浅** — 不能抢节点的视觉主体地位
5. **文字颜色比边框深** — 确保可读性

## 如何新增配色方案

本文件是纯数据驱动，无需改任何代码，追加一个方案块即可被自动发现和使用。

### 步骤

1. 在本文件末尾追加一个方案块，**角色行名必须与现有方案完全一致**（这是引擎识别角色的 key），格式：

```markdown
## 方案六：你的方案名

适合：一句话描述适用场景

| 角色          | fillColor | strokeColor | fontColor |
|--------------|-----------|-------------|-----------|
| 主要节点      | #填色     | #边框色     | #文字色   |
| 次要节点      | #填色     | #边框色     | #文字色   |
| 强调/警告     | #填色     | #边框色     | #文字色   |
| 成功/通过     | #填色     | #边框色     | #文字色   |
| 错误/危险     | #填色     | #边框色     | #文字色   |
| 数据/存储     | #填色     | #边框色     | #文字色   |
| 连线默认      | -         | #连线色     | #连线色   |
| 背景分区      | #填色     | #边框色     | #文字色   |
```

2. （可选）让 mermaid / excalidraw 引擎也支持：在 `mermaid-themes.md` 和 `excalidraw-colors.md` 中追加**同名方案块**，颜色值保持一致。

3. 同步到已安装的 skill 副本（如果安装的是拷贝而非源仓库）：

```bash
rsync -a --exclude='.git' --exclude='examples' <本仓库路径>/ ~/.claude/skills/drawskills/
```

### 配色设计约束

- 遵循上方"使用原则"5 条
- fillColor 用浅色（接近白色的低饱和度），strokeColor 用同色系深色，fontColor 用最深色
- 建议从 Material Design 色板取色：浅色取 `Xx 50/100`，深色取 `Xx 700/800`
- handsvg / drawio 引擎生成时会自动按规则补 `light-dark()` 深色模式值（填充取互补暗色、描边提亮），无需在表中写深色值

### 使用新方案

画图时直接说：「用 <方案名> 配色画个流程图」。引擎读取本文件时按方案名匹配。
